- **S4 `04_save_chat_log.py`:** `open(path, mode)` with `"r"`/`"w"` (empties the file)/`"a"`, `with ... as f:` closes the file for you (like a Ruby `File.open` block, unlike PHP `fopen`/`fclose`), `encoding="utf-8"`, `f.write()` adds no `\n`, `for line in f` + `.rstrip("\n")`, `f.read()` = `file_get_contents`, `FileNotFoundError`, `pass`, `.split(": ", 1)` (max CUTS; PHP/Ruby limit = max PARTS), unpacking `a, b = [x, y]`, relative paths are relative to the cwd. Plain text breaks on newlines, so JSON comes in S8.
- **S5 `05_chat_log_class.py`:** `class ChatLog:` (PascalCase, indented block, no braces/`end`), `__init__` = constructor (`__construct`/`initialize`/`constructor`), returns nothing, explicit `self` as the first param of every method (PHP `$this`, Ruby/JS implicit), attributes made by assigning `self.x = ...` (no declarations; forgetting `self.` makes a local), no `new`: `ChatLog(path)`, `log.load()` = `ChatLog.load(log)`, dunder methods = PHP magic methods: `len(x)` calls `x.__len__()`, `__str__` = `__toString`/`to_s`. Same `chat_log.txt` format as S4, so it loads the S4 log. Payoff: S8 can switch save/load to JSON without touching the main program.
- **S6 `06_modules/` (`main.py` + `chat_log.py`):** every `.py` file is a module, named after its file (so it must start with a letter); everything at the top level is importable, no `export` (unlike JS); `import datetime` → `datetime.date.today()`, `import random as rnd` (like `import numpy as np`), `from chat_log import ChatLog` (≈ JS named import, PHP `use` + autoload, Ruby `require_relative`); imports are found in the RUN script's folder, while `open()` paths are relative to the cwd; importing RUNS the module, once only (cached); `__name__` is `"__main__"` when run directly, else the module name, so the `if __name__ == "__main__":` guard ≈ Ruby `if __FILE__ == $0` (PHP has no equivalent); import order: stdlib first, own modules last; avoid `import *`; `__pycache__/` = compiled cache, gitignored.
- **S7 `07_packages.py` + `requirements.txt` + `.env.example`:** `pip` = composer/bundle/npm, `requirements.txt` = composer.json/Gemfile (`==` pins; `pip freeze` ≈ lock file), `.venv/` ≈ vendor/node_modules, but pip installs into whichever Python runs it, so a venv gives each project its own Python + packages; `python3 -m venv .venv`, `source .venv/bin/activate` (puts `.venv/bin` first on PATH), `deactivate`; Homebrew Python refuses pip outside a venv (`externally-managed-environment`, PEP 668); the pip name can differ from the import name (`python-dotenv` → `import dotenv`, PyPI ≈ Packagist); `ModuleNotFoundError`; `sys.executable`, `sys.prefix != sys.base_prefix` = in a venv; `sys.exit(1)`; `load_dotenv()` finds `.env` next to the script (not the cwd), doesn't override real env vars (like Laravel); `os.environ.get(k, default)` = `env()`/`ENV.fetch`/`process.env`, values are always strings; slice `s[:7]` = `substr($s, 0, 7)`; never print a full API key. uv + pyproject.toml mentioned as the modern alternative.
- **S8 `08_json_api/` (`chat_log.py` + `main.py`):** `import json` (stdlib); `dumps`/`loads` = string (`json_encode`/`json_decode($s, true)`, `JSON.stringify`/`parse`), `dump`/`load` = file; dict↔object, list↔array, `None`↔null, `True`↔true; parsed JSON is always dicts (no dot access); `indent=2` (= JSON_PRETTY_PRINT), `ensure_ascii=False` (= JSON_UNESCAPED_UNICODE); invalid JSON raises `json.JSONDecodeError` (PHP returns null); several `except` blocks per `try`; `==` compares lists/dicts by value (JS compares references); `type(x)`. `ChatLog` save/load switched to JSON and the code using it is unchanged (the S5 payoff); saves `chat_log.json`. `requests.post(url, json=payload, timeout=10)` (`json=` dumps the body and sets Content-Type, like Laravel `Http::post`; synchronous, no await; NO default timeout), `raise_for_status()` (= `->throw()`), `.json()`, `requests.get(url, params=...)`; `except requests.RequestException as error` (the parent of all requests errors); `list.pop()`; `[-1]` = last item; nested `data["json"]["messages"]`; `( ... )` lets an expression span several lines, and adjacent strings join into one. The echo server is httpbin.org/post (free, no key). The payload is shaped like an AI request (`model`, `max_tokens`, `messages`), and every call sends the full history (APIs are stateless). pip pulls in dependencies (urllib3, certifi...); `requirements.txt` lists only direct imports.
- **S9 `09_type_hints.py`:** hints are NEVER checked at runtime (unlike PHP's TypeError); like TypeScript/Sorbet, they're for the editor and **mypy** (≈ PHPStan/Larastan, run as `mypy file.py`, installed via pip, not imported); `def f(self, x: str, n: int = 100) -> None:` (`-> None` = `: void`, default goes after the hint, `self` unhinted, `__init__` always `-> None`); `self.messages: list[Message] = []` (empty containers need a hint); `list[str]`, `dict[str, int]` (PHP only has `array`; PHPStan `list<...>`); `X | None` = `?X`, so check `if found is not None:` before indexing (mypy: "not indexable"); `from typing import Any, Literal, TypedDict`: `Any` = `mixed`, `Literal["user", "assistant"]` ≈ enum / TS union, `Role = ...` makes a type alias; `class Message(TypedDict)` types a dict's keys (PHPStan `array{role: string}`), still a plain dict at runtime (same shape the anthropic SDK uses); hints are stored in `f.__annotations__`. Saves `typed_chat_log.json`.
- **vs PHP/Ruby:** indentation = blocks; `True`/`False`/`None` case-sensitive; strict types (`int("abc")` → ValueError, no type juggling); `'` = `"`, interpolation only in f-strings (like JS template literals `` `${x}` ``)
- **vs JS:** `None` replaces both `null` and `undefined`; `==` is already strict (no `===`); `parseInt("abc")` → NaN in JS, but Python raises an error
